# Simple Interest Calculator

## Description
This project explains how to calculate simple interest using the principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

Where:
- **Principal (P):** Initial amount of money
- **Rate (R):** Annual rate of interest in percentage
- **Time (T):** Time period in years

## Example
If the principal is ₹1000, the annual interest rate is 5%, and the time period is 2 years:

Simple Interest = (1000 × 5 × 2) / 100 = ₹100

Total Amount = Principal + Simple Interest = ₹1100

## Purpose
The purpose of this project is to understand the simple interest calculation formula and practise using Git and GitHub for version control.
